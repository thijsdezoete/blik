{% trans 'How advice works' %}

{% trans 'Advice is a tip for the person who gets the report. The report shows it only when reviewers give this question a low score.' %}

{% trans 'Where it shows' %}

{% trans 'In the report, in the part "Skill level", under "Action Items". So advice shows only in a report that has a skill level.' %}

{% trans 'How to write it' %}

  • {% trans 'Write to the person who reads the report, as one thing to do. Example: "Ask a colleague to read your next proposal before you send it."' %}
  • {% trans 'Keep it short: one sentence.' %}
  • {% trans 'You can use {name} for the first name of the person.' %}

{% trans 'When the report shows it' %}

  • {% trans 'The score of this question is the average of what the others answered, on a scale of 1 to 5. The own answer of the person does not count.' %}
  • {% trans 'The report shows the advice when that score is below the number you choose for this question. With 3, the advice shows for a score of 2.9 and not for a score of 3.' %}
  • {% trans 'Every answer type counts on the scale of 1 to 5 here, also a slider from 1 to 10.' %}

{% trans 'Advice per stage' %}

  • {% trans 'Advice in the row "Every stage" goes to every person. Advice in the row of a stage, for example Novice, goes only to a person at that stage.' %}
  • {% trans 'A person gets the advice of "Every stage" and the advice of their own stage.' %}
  • {% trans 'To move advice to another stage, drag it by its handle to that row. Or choose the stage in "Move to...".' %}

{% trans 'Pay attention' %}

  • {% trans 'The report has room for three lines under "Action Items". With advice on many questions, only the first ones show. So give advice for the questions that matter most, not for every question.' %}
  • {% trans 'Advice is a text of the questionnaire: it is translated on the language tabs, like the questions.' %}
