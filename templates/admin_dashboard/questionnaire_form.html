{% trans 'What is Weighted Scoring?' %}

{% trans 'Weighted scoring lets you assign numeric values to each choice option. This allows choice-based questions to contribute to:' %}

  • {% trans 'Section averages and overall scores' %}
  • {% trans 'Performance charts and visualizations' %}
  • {% trans 'Insights & analytics (strengths/development areas)' %}
  • {% trans 'Comparisons across review cycles' %}

{% trans 'How It Works' %}

{% trans 'Single Choice (Dropdown)' %}

{% trans 'User selects ONE option. Score = weight of selected option.' %}

{% trans 'Example:' %} "{% trans 'How would you rate their communication?' %}"
• {% trans 'Excellent Communication' %} → 5
• {% trans 'Good Communication' %} → 4
• {% trans 'Average Communication' %} → 3
• {% trans 'Needs Improvement' %} → 2
• {% trans 'Poor Communication' %} → 1

{% trans 'If user selects "Good" → Score: 4' %}

{% trans 'Multiple Choice (Checkboxes)' %}

{% trans 'User selects MULTIPLE options. Score = sum of selected option weights.' %}

{% trans 'Example:' %} "{% trans 'Which leadership qualities do they demonstrate?' %}"
• {% trans 'Strategic thinking' %} → 5
• {% trans 'Team motivation' %} → 5
• {% trans 'Clear communication' %} → 4
• {% trans 'Delegation' %} → 4
• {% trans 'Time management' %} → 3

{% blocktrans trimmed %}If user selects "Strategic thinking" + "Clear communication" + "Team motivation"
→ Score: 5 + 4 + 5 = 14 (rewards demonstrating more qualities){% endblocktrans %}

{% trans 'Note:' %} {% blocktrans trimmed %}Multiple choice uses SUM (not average) to reward selecting more positive attributes. This makes it ideal for competency checklists where more is better.{% endblocktrans %}

{% trans 'Best Practices' %}

  • {% trans 'Use consistent scales:' %} {% trans 'Stick to 1-5 or 1-10 throughout your questionnaire' %}
  • {% trans 'Higher = Better:' %} {% trans 'Assign higher weights to more positive/desirable options' %}
  • {% trans 'Frequency questions:' %} {% trans 'Daily=5, Weekly=4, Monthly=3, Rarely=2, Never=1' %}
  • {% trans 'Competency checklists:' %} {% trans 'Weight by importance/difficulty level, or set all weights to 1 to simply count how many competencies were selected' %}
  • {% trans 'Equal weighting:' %} {% trans 'For multiple choice questions where all options are equally valuable, set all weights to 1. This creates a simple counter (3 selections = score of 3)' %}
  • {% trans 'Skip scoring when:' %} {% trans 'Choices are purely categorical (e.g., department names, roles)' %}

{% trans 'Tip:' %} {% blocktrans trimmed %}You can leave scoring disabled for simple multiple choice questions. Enable it only when you need numeric analytics for that specific question.{% endblocktrans %}
